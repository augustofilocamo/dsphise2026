1) Cambios clave en HISE scripts
------------------------------------------------------------

A) Scripts/ScriptProcessors/grid-to-human/Interface.js

1. Tempo knob con sync:
   - El knob “Tempo” ahora acepta -1:
     - bpmKnob.setRange(-1, 300, 1)
   - getEffectiveTempoBpm():
     - Si Tempo == -1: usa Engine.getHostBpm() (con fallback a BPM interno)
     - Si Tempo != -1: valida rango y usa BPM fijo si corresponde
   - onTempoControl():
     - Si value == -1: Engine.setHostBpm(-1)
     - Si value != -1: Engine.setHostBpm(value)
   - Label del knob:
     - Cuando Tempo == -1 muestra texto “Tempo Synced” (en hover y estado normal)

2. Timing/animación de grilla usando tempo efectivo:
   - La grilla (gridAnimTimer) y collectGridData* usan getEffectiveTempoBpm()
   - Así los cálculos de timing se alinean al host cuando Tempo == -1.

3. Arreglo “cluster al final” al mostrar 2 bars:
   - loadExportedMidiIntoPlayer(player, playerName, midPath, numBars, sourceBars)
   - Se recortan los eventos si numBars < sourceBars (filtrado por timestamp < cutoff)
   - Evita que las notas de bars no mostrados se acumulen al final.

4. Expand dinámico con expandSizeComboBox:
   - ExpandPlayerLoadFull(...) ya no usa un fijo 8 bars.
   - Pasa el valor del combo (topX) como numBars.
   - sourceBars se toma de match.bars (o fallback LastMatchBars).
   - loadExportedMidiIntoPlayer usa sourceBars para recortar correctamente.

5. Samplemap switching (Sampler1):
   - Synth.getChildSynth("Sampler1").asSampler().loadSampleMap(sampleMapId)
   - btnAccoustic -> loadSampleMap("sfz2") y pone btnElectronic a 0
   - btnElectronic -> loadSampleMap("electrokit") y pone btnAccoustic a 0
   - IMPORTANTE: los IDs de componentes deben existir como:
     - "btnAccoustic"
